# 实验室项目展示板

## 项目简介

一个用来展示实验室项目的小网页：能看到有哪些项目、每个项目是谁在做、用了什么技术、进展如何。

**这是我学习前端的第一个练习项目**，目的是搞懂 Vue 3 是怎么写页面的，不是要给谁上线用。所有数据都存在自己的浏览器里，没有后端、没有数据库，也没有登录功能。

---

## 已实现功能

- 展示项目列表，每张卡片包含：项目名称、简介、成员、技术栈、状态、GitHub 地址
- 新增项目（点按钮弹出表单填写）
- 删除项目（带二次确认，防止误删）
- 按项目名称搜索（输入即过滤，支持搜中间几个字）
- 数据存在浏览器本地，刷新页面、关掉浏览器再打开都还在
- 项目状态固定三种：进行中 / 已完成 / 暂停，不同状态用不同颜色标识

## 使用技术

| 技术 | 说明 |
| --- | --- |
| Vue 3 | 前端框架，用的是组合式 API（`<script setup>` 写法） |
| Vite | 项目脚手架和开发服务器，负责启动项目和打包 |
| 原生 CSS | 没用任何 UI 组件库，样式都是手写的 |
| localStorage | 浏览器自带的本地存储，用来代替数据库 |

没有后端、没有数据库、没有用户系统。

## 如何安装

1. 电脑上需要先装好 **Node.js**（我用的版本是 v22.22.2）

2. 打开终端，进入项目文件夹：

   ```bash
   cd lab-project-board
   ```

3. 安装依赖：

   ```bash
   npm install --registry=https://registry.npmmirror.com
   ```

   > 后面那串是国内镜像地址。不加的话会去连国外的服务器，我这里试过，等十分钟都装不完。

## 如何运行

启动开发服务器：

```bash
npm run dev
```

然后在浏览器打开 **http://localhost:5173** 就能看到页面。改完代码保存，页面会自动刷新，不用手动重启。

其他两条命令：

```bash
npm run build    # 打包成成品，输出到 dist/ 文件夹
npm run preview  # 本地预览打包后的效果
```

## 我通过这个项目学到了什么

按做的先后顺序记的，都是当时真的卡住过或者想明白的点：

1. **Vue 项目是怎么跑起来的**：浏览器先拿到 `index.html`（里面只有一个空的 `div#app`），再执行 `main.js`，由它把 `App.vue` 挂到那个空 div 上。整个项目只有一个 HTML 页面。

2. **几个核心语法**：
   - `ref` —— 数据用它包一层，改了页面才会自动更新（`<script>` 里要写 `.value`，模板里不用）
   - `v-for` —— 数组里有几条就渲染几遍，不用复制粘贴
   - `v-model` —— 输入框和变量自动同步，省掉手写取值
   - `v-if` / `v-else` —— 按条件决定显示哪一块
   - `computed` —— 依赖的数据一变就自动重算，搜索过滤就是这么做的

3. **最重要的一条思路**：**改数据，不要直接操作页面**。以前想"删掉一个元素"要去操作 DOM，现在只要把数组里那条数据去掉，页面自己就变了。

4. **踩过的坑（都真实发生过）**：
   - 表单提交忘了加 `.prevent`，点保存会整页刷新，填的东西全没了
   - 删除项目原来用数组下标，加了搜索功能之后下标会错位、删错项目 —— 改成用项目对象本身才对
   - 状态文案一开始既存英文又存中文两份，改文案时旧数据对不上 —— 后来改成只存英文值，显示时查表，旧数据不用迁移就自动生效
   - 页面白屏时不要慌，看编译报错：`[vue/compiler-sfc]` 那条信息会直接告诉你是第几行少了个逗号。**而且报错行号常常比真正出错的那一行晚一行**，要往上一行找

5. **本地存储**：`localStorage` 只能存字符串，所以数组进出都要用 `JSON.stringify` / `JSON.parse` 转一下。它的局限是换电脑、换浏览器数据就没了，真要多人共享得上后端。

6. **用 Git 管理版本**：文件改坏了能对比、能回滚。这个项目就是在被改坏一次之后才想起来建 Git 的。
